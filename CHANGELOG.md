# Changelog

All notable changes to **yaraforge** are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) | Versioning: [SemVer](https://semver.org/)

## [1.1.0] - 2025-03-10
### Added
- AI-generated YARA rule synthesis from threat intelligence text
- Deployment adapters for Elastic, Splunk, and standalone YARA
- Automated rule validation and false-positive testing pipeline
- Ransomware, webshell, and generic malware rule bundles

## [1.0.0] - 2024-12-01
### Added
- Initial release: YARA rule forge with AI rule generation
- CLI interface for rule creation, testing, and deployment
- Structured rule repository (malware, ransomware, webshells)
